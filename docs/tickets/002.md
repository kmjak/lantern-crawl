# 002: ゲームロジック

## Background
docs/context/game-design.md のルールを、DOM に依存しない純粋なロジックとして実装する。

## Requirements
- `src/client/game.js`：盤面生成（初手の 3×3 は安全）、数字計算、公開と 0 の連鎖公開、回復薬、戦闘、レベルアップ、クリア／ゲームオーバー、メモ、スコア計算
- 乱数を差し替え可能にする（テストで再現できるように）
- 設定値は 1 つの config オブジェクトにまとめる
- Node からも読み込めること

## Acceptance Criteria
- 上記ルールそれぞれに単体テストがあり `npm test` が通る
- デザイン上クリア可能であること（全敵の XP で Lv5 に届き、Lv5 でボスに勝てる）をテストで確認
