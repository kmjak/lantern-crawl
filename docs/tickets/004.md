# 004: ランキング

## Background
スコアを共有ランキング（Google スプレッドシート）に保存・表示する。

## Requirements
- サーバー：`submitScore(entry)` と `getRanking()`（上位 10 件）
  - 入力検証（ニックネーム 1〜12 文字・制御文字除去、数値の範囲チェック）
  - `LockService` で書き込みを排他
  - シートはスクリプトプロパティに保存した ID を使い、無ければ自動作成
- クライアント：終了画面でニックネーム入力→送信、ランキング表示
- ローカルプレビューでは `localStorage` スタブで動く
- 検証・並べ替えロジックは Node でテストできる形にする

## Acceptance Criteria
- ローカルプレビューで送信・表示ができる
- 検証・ソートの単体テストが通る

## Out of Scope
- 不正スコア対策（クライアント計算のため v1 では対象外）
