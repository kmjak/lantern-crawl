# 001: プロジェクトの土台（ビルド・テスト・ローカルプレビュー）

## Background
GAS の web アプリとして動かしつつ、ローカルでもテスト・プレビューできる開発環境が要る。

## Requirements
- `package.json`（依存なし）に `build` / `test` スクリプト
- `src/` の構成（docs/context/overview.md の Architecture のとおり）と最小のページ
- `scripts/build.mjs`：`build/gas`（clasp 用、css/js を html パーシャル化）と `build/local/index.html`（全部インライン＋`google.script.run` スタブ）を生成
- `README.md`、`.gitignore`
- テスト実行の土台（`node --test`）

## Acceptance Criteria
- `npm run build` で `build/gas` と `build/local/index.html` ができる
- `build/local/index.html` をブラウザで開くとページが表示される
- `npm test` が通る

## Out of Scope
- ゲームロジック・UI の中身（002 / 003）
- ランキング（004）、デプロイ（005）
