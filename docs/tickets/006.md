# 006: GitHub Pages への移行（ランキング削除）

## Background
デプロイ先が GitHub Pages になった。Pages は静的ファイルのみなので、GAS のサーバー処理（`doGet`・スプレッドシートのランキング）は動かない。ゲーム本体はブラウザだけで完結しているため、そのまま静的サイトとして公開できる。

## Requirements
- ランキング機能を削除する（サーバー、検証ロジック、登録フォーム、ランキングパネル、関連テスト）。終了画面のスコア表示は残す
- GAS 向けのビルド・設定を削除し、単一の静的ページ `build/site/index.html` を生成する
- GitHub Actions で Pages に自動デプロイする（main への push 時）
- README と `docs/context/**` を更新する

## Acceptance Criteria
- `npm run build` で `build/site/index.html` が生成され、ブラウザで最初から最後まで遊べる
- `npm test` が通る
- Pages の URL でゲームが遊べる

## Out of Scope
- 外部 DB を使った共有ランキング（今回は入れない）
- GAS プロジェクトの削除（Drive 側に残る。必要ならユーザーが削除）
