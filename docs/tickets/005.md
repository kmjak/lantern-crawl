# 005: GAS へのデプロイ

## Background
実際に web アプリとして公開し、URL で遊べるようにする。

## Requirements
- `clasp` で GAS プロジェクトを作成し `.clasp.json` を用意（rootDir は `build/gas`）
- `npm run deploy` 相当の手順（build → push → deploy）
- web アプリ設定：実行ユーザーは自分、アクセスは全員（匿名）
- README にデプロイ手順と公開 URL

## Acceptance Criteria
- 公開 URL でゲームが遊べ、ランキングがスプレッドシートに保存される

## Out of Scope
